## How to Get Recognized

This project adheres to the [all-contributors](https://github.com/all-contributors/all-contributors) specification.

Whenever you contribute to this project, you can request recognition by commenting on any pull request or issue:

```text
@all-contributors please add @your-username for code, doc
```

The All Contributors bot will automatically update `.all-contributorsrc` and open a pull request adding your profile to this page.
