# Project Analysis: `Ruff` (astral-sh/ruff)

## 1. Project Overview
- **Repository**: `https://github.com/astral-sh/ruff`
- **Documentation Type**: High-performance Python linter and formatter written in Rust.
- **Doc Generator**: MkDocs + MkDocs Material.

---

## 2. Configuration & Features Inventory
- **Rule Docs Generation**: Auto-generated documentation pages for hundreds of linter rules generated by Rust tooling (`cargo dev generate-docs`).
- **Markdown Extensions**:
  - `pymdownx.superfences`
  - `pymdownx.tabbed`
  - `pymdownx.inlinehilite`
  - `pymdownx.highlight`
  - `admonition`
- **Navigation Structure**: Deep hierarchical rule catalog, configuration settings reference, and contributor guides.

---

## 3. Subsystem Classification Breakdown

### Automatic:
- `nav:` hierarchy $\longrightarrow$ `toctree` hierarchy
- `admonitions` (`!!! note`, `!!! warning`) $\longrightarrow$ MyST `{note}`, `{warning}`
- `pymdownx.tabbed` content tabs $\longrightarrow$ `sphinx-design` `tab-set`
- Code blocks and inline highlighting $\longrightarrow$ MyST code blocks

### Review:
- Package dependencies (`pyproject.toml` docs group)
- CI workflows (`.github/workflows/docs.yml`)
- Deployment targets (GitHub Pages / Cloudflare Pages)

### Manual:
- Integration with external Rust doc generator scripts (`cargo dev generate-docs`) targeting MkDocs markdown output formats.
