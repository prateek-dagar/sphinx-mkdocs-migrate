# Security Policy

## Supported Versions

We actively support and provide security updates for the latest released version and the active development branch:

| Version | Supported |
| :--- | :--- |
| Latest release (`>= 0.0.1`) | :white_check_mark: |
| Active development branch (`main`) | :white_check_mark: |
| Superseded / older releases | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability within `sphinx-mkdocs-migrate`, please report it responsibly rather than opening a public issue.

Please report security issues privately via GitHub's native **Private Vulnerability Reporting**:
👉 [**Submit a Security Advisory Report**](https://github.com/prateek-dagar/sphinx-mkdocs-migrate/security/advisories/new)

GitHub Security Advisories allow you to disclose vulnerabilities confidentially directly to the maintainers without exposing details publicly or requiring email exchange. Maintainers can collaborate with you in a private discussion, work on a fix in a private temporary fork, and coordinate a secure release.

Please include in your report:
- A description of the vulnerability and affected components.
- Steps or a minimal test project to reproduce the vulnerability.
- Potential impact or attack vectors.

We will review your vulnerability report within 48 hours and coordinate a timely fix and security advisory release.
